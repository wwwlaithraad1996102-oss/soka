# SOKA v2 — Supabase-connected

نسخة SOKA v2 ثابتة تعمل على Vercel، ومتصلة بـ Supabase عبر `supabase-js` في المتصفح.

## 1) إعداد Supabase

قاعدة البيانات الأساسية يجب أن تكون منشأة كما في النسخة السابقة. ثم افتح Supabase → SQL Editor وشغّل ملف:

`supabase_admin_policies.sql`

هذا يضيف سياسات CRUD للمدير فقط.

## 2) إعداد الاتصال

افتح `config.js` واستبدل:

- `supabaseUrl` = Project URL
- `supabaseAnonKey` = Publishable key / anon key

**ممنوع وضع `service_role` key في الموقع أو GitHub.**

المفتاح العام/Publishable أو anon مصمم للاستخدام مع RLS، لذلك حماية البيانات تعتمد على سياسات RLS في Supabase.

## 3) النشر على Vercel

ارفع الملفات إلى مستودع GitHub ثم اربط المستودع بمشروع Vercel. أي push جديد إلى `main` يعيد النشر تلقائيًا إذا كان الربط مفعلًا.

## 4) الميزات الموجودة

- تسجيل الدخول بـ Supabase Auth
- إنشاء حساب
- اكتشاف حساب المدير عبر `profiles.role`
- عرض الأفلام والمسلسلات من قاعدة البيانات
- صفحات تفاصيل الفيلم والمسلسل
- المواسم والحلقات
- مشغل فيديو HTML5 للرابط الموجود في `video_url`
- البحث
- لوحة تحكم المدير
- إضافة/حذف الأفلام
- إضافة/حذف المسلسلات
- إضافة/حذف المواسم
- إضافة/حذف الحلقات
- إحصائيات أساسية

## 5) ملاحظة الحقوق

استخدم فقط صورًا وفيديوهات تملك حقوق استخدامها أو لديك ترخيص لبثها على الموقع.
